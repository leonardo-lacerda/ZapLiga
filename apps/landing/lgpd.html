1. Nosso compromisso com a LGPD

O ZapLiga trata chamadas de voz para leads, o que envolve dados pessoais em duas frentes: os dados de quem usa a plataforma (clientes e SDRs) e os dados dos leads chamados, importados pelos nossos clientes. Tratamos ambos seguindo os princípios da Lei Geral de Proteção de Dados, com base legal definida, minimização de dados e controle de acesso.

2. Base legal para tratamento

Dados de conta e uso da plataforma são tratados com base na execução do contrato entre a ZapLiga e o cliente. Dados de leads importados são tratados com base no legítimo interesse do cliente na prospecção comercial, sendo responsabilidade do cliente garantir que o contato está de acordo com a base legal aplicável ao seu caso.

3. Papéis: controlador e operador

Para os dados de leads que o cliente importa e usa para discagem, o cliente atua como controlador dos dados, e o ZapLiga atua como operador, processando esses dados exclusivamente conforme as instruções do cliente. Para dados de cadastro e uso da própria plataforma, o ZapLiga atua como controlador.

4. Direitos do titular de dados

Qualquer titular de dados pessoais, incluindo um lead que recebeu uma chamada, tem direito a:

  • Confirmação da existência de tratamento e acesso aos dados;
  • Correção de dados incompletos, inexatos ou desatualizados;
  • Anonimização, bloqueio ou eliminação de dados desnecessários;
  • Portabilidade dos dados a outro fornecedor;
  • Eliminação dos dados tratados com consentimento, quando aplicável;
  • Revogação do consentimento e oposição a tratamentos irregulares.

5. Como exercer seus direitos

Clientes e usuários da plataforma podem exercer esses direitos diretamente pelo painel ou pelo suporte. Um lead que deseja exercer algum desses direitos sobre uma chamada recebida deve contatar diretamente a empresa que realizou o contato, já que é ela quem controla esses dados. Se preferir, pode também nos escrever e encaminharemos a solicitação ao cliente responsável.

6. Segurança e descarte de dados de leads

Dados de leads ficam armazenados apenas enquanto a fila ou o histórico de chamadas estiver ativo na conta do cliente. O cliente pode solicitar a exclusão de uma lista de leads a qualquer momento, e os dados são removidos dos nossos sistemas de produção dentro do prazo informado no painel.

7. Encarregado de dados (DPO)

Nosso encarregado de proteção de dados pode ser contatado pelo e-mail dpo@zapliga.com.br para dúvidas, solicitações ou denúncias relacionadas ao tratamento de dados pessoais pela plataforma.
