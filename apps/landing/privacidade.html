Política de privacidade.

Como tratamos dados de clientes, usuários da plataforma e dos leads chamados através do ZapLiga.

1. Dados que coletamos

Coletamos três categorias de dados:

  • Dados de cadastro: nome, e-mail, empresa e telefone de quem cria uma conta ou é convidado como SDR.
  • Dados de uso da plataforma: registros de chamadas, status de leads, métricas de números e logs de acesso, usados para operar e melhorar o serviço.
  • Dados de leads chamados: nome e número de WhatsApp importados pelo cliente para compor a fila de discagem, tratados exclusivamente em nome do cliente.

2. Como usamos os dados

Usamos os dados para operar o motor de chamadas, gerar métricas de desempenho, dar suporte técnico e cumprir obrigações legais. Dados de leads importados pelo cliente são usados exclusivamente para realizar as chamadas solicitadas por aquele cliente, nunca para fins próprios da ZapLiga.

3. Compartilhamento com terceiros

Compartilhamos dados apenas com fornecedores necessários para operar a plataforma, como provedores de infraestrutura e da API de chamadas de voz do WhatsApp, sempre sob contrato de confidencialidade. Não vendemos dados pessoais a terceiros.

4. Armazenamento e segurança

Os dados são armazenados em ambiente com controle de acesso, criptografia em trânsito e monitoramento contínuo. O acesso interno é restrito à equipe que precisa dele para prestar o serviço.

5. Retenção de dados

Mantemos os dados enquanto a conta estiver ativa e pelo período necessário para cumprir obrigações legais. O cliente pode solicitar a exclusão de dados de leads a qualquer momento pelo painel ou pelo suporte.

6. Seus direitos

Você pode solicitar acesso, correção, portabilidade ou exclusão dos seus dados pessoais a qualquer momento. Detalhes completos sobre o exercício desses direitos, incluindo os direitos previstos na LGPD, estão descritos na nossa página de LGPD.

7. Cookies

Usamos cookies essenciais para manter sua sessão ativa na plataforma e cookies de análise para entender o uso do site, sempre com opção de recusar cookies não essenciais.

8. Contato do encarregado de dados

Para exercer seus direitos ou tirar dúvidas sobre esta política, fale com nosso encarregado de proteção de dados pelo e-mail privacidade@zapliga.com.br.
